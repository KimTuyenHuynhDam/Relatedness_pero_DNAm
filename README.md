# Parental Kinship Influences Global Methylation and Epigenetic Age Estimation in *Peromyscus*

This repository contains the R code, statistical workflows, and source data used in the study **"Parental kinship influences global methylation and epigenetic age estimation in *Peromyscus*"**, published in *GENETICS*.

## 📌 Overview

Inbreeding and parental relatedness are known to affect offspring fitness, but their impact on the epigenome remains understudied. This project leverages detailed pedigrees of captive *Peromyscus* (deer mice) to explore how parental relatedness impacts global DNA methylation and epigenetic age estimation.

**Key Findings:**
* Parental relatedness positively impacts lifespan expectancy and reduces epigenetic aging estimates.
* The effect is partially mediated by structured methylome variation (Principal Components).
* Methylation changes are not random but cluster at specific neurodevelopmental loci (e.g., *Zic1/Zic4*, *Gsx2*) on Chromosomes 7 and 10.
* A specific methylation signature was developed to predict parental relatedness with high accuracy ($R^2 = 0.957$).
